STEALTH 5S HARD EXE ARGUMENT FIX — WORK CANDIDATE
Target: World of Warcraft 1.12.1 build 5875 x86

Problem
-------
The existing EXE hard patch detours the central cooldown-entry insertion routine
at VA 0x006E12C0 to VA 0x0075D401 and contains a 5000 ms clamp for Stealth
ranks 1784..1787. Binary inspection of the active EXE showed the selector used:

    0x0075D401: mov eax,[esp+0x14]

Inspection of the real callers of 0x006E12C0 shows that spellId is argument #1,
therefore it is at [esp+0x04] before the original function prologue. The old
selector was checking argument #5 and could fail to recognize Stealth.

Patch
-----
Only one byte changes in the active EXE:

    VA:          0x0075D401
    raw offset:  0x0035D401
    old bytes:   8B 44 24 14    mov eax,[esp+0x14]
    new bytes:   8B 44 24 04    mov eax,[esp+0x04]

The existing 5000 ms writes remain unchanged:

    mov dword ptr [esp+0x10],0x1388
    if [esp+0x1C] > 0x1388: [esp+0x1C] = 0x1388

# WoW112 Guardian

The workflow runs at minute 17 of every UTC hour, subject to GitHub Actions scheduler delays. It must be installed on the default branch main to run hourly. It may also be run manually using workflow_dispatch.

The auditor checks the current main/work/parallel SHA, each branch's CURRENT.json and runtime/current.json, ordered active DLL manifest, exact-SHA workflow failures, duplicate DLLs, shared canonical source paths and work ancestry. It upserts a single tracking issue and uploads machine-readable JSON evidence. This bounded audit cannot establish actual in-game safety or detect every hook collision.

Without an OPENAI_API_KEY repository Actions secret, audit-only mode is active. When the key is set, at most one minimal model-proposed repair is attempted each run, only on a failing work/parallel HEAD whose last commit modified exactly one currently active C source file. Source and logs are treated as untrusted data. There are strict unique-replacement, size, line-count and hook/address guards; no model-generated workflow, verifier, runtime manifest or metadata edits are permitted.

The proposal is committed to a short-lived feature/guardian-<branch>-<sha> branch and opened as a draft pull request to its originating development branch. No automatic merge, main change, promotion or gameplay claim occurs. A separate explicitly dispatched exact-SHA Windows candidate gate runs repository verification, native build and final package verification. Only diagnostic metadata, never an unaccepted playable ZIP, is uploaded by that gate. An in-game test is still required before any promotion or merge.

The external OpenAI API key is separately billed and is not included in a ChatGPT subscription. Configure the Actions secret OPENAI_API_KEY to enable code proposals; remove it to revert to audit-only mode. GitHub repository Actions settings must allow GitHub Actions to create pull requests. If a create-PR permission is disallowed, audits continue and the repair status records the problem. Scheduled jobs may be delayed or omitted by GitHub. GITHUB_TOKEN-created ordinary push events do not trigger follow-on builds; the gate uses workflow_dispatch instead.

The Guardian report is evidence tied to a particular branch SHA, not an attestation that a source patch runs in WoW 1.12.1 build 5875 x86. Review draft PRs and candidate gate results before integration.


## Free hybrid mode (Windows 11, RTX 3060 Ti 8 GB, 32 GB RAM)

The default-branch hourly cloud audit is **audit-only**: the scheduled workflow intentionally does not read OPENAI_API_KEY. If an older OPENAI_API_KEY secret exists it is ignored by that workflow. GitHub retains the canonical issue and JSON audit artifact even while the user's Windows PC is off.

On Windows, open PowerShell as the current Windows user and run the versioned [local installer](../tools/install_guardian_local.ps1). It installs GitHub CLI, Ollama and Python 3.12 through winget only if missing, authenticates GitHub interactively, retrieves both Python scripts from one verified main commit and downloads qwen2.5-coder:7b. It registers a Windows hourly scheduled task called WoW112GuardianLocal that runs while that user is logged in. **Local AI cannot run while the PC is off**; the next local check compares live GitHub HEADs and catches up on outstanding current failures. The local install is pinned until the installer is rerun; its installed SHA is printed. The user must approve Windows installations and GitHub browser sign-in; GitHub cannot install software on the user's PC remotely.

The local process gets a short-lived GitHub CLI token from the OS credential manager and sends prompts only to 127.0.0.1:11434 Ollama, never to paid OpenAI API. Do not store credentials in scripts or paste tokens in chat. Ollama must be running when the scheduled task fires. Local AI optimization reviews rotate across active canonical C sources on work and parallel, even when CI is green. Only model-sized sources (at most 12 KB) are sent to the 7B model; at most one file is reviewed per local run. A candidate requires an exact unique replacement (at most 40 changed lines), a documented equivalence rationale and a reproducible measurement plan. The model may return no proposal, and no speedup is claimed without a benchmark or game test. If the model cannot prove a repair, it skips. Proposed changes are isolated draft PRs and require independent exact-SHA native checks plus human/in-game review; neither branch integration nor promotion is autonomous.

Local results: %LOCALAPPDATA%\\WoW112Guardian\\last_run.json and last_run.log. Run immediately with `schtasks /Run /TN WoW112GuardianLocal`. To disable locally: `schtasks /Delete /F /TN WoW112GuardianLocal`. Rerun the installer after an accepted change to local bridge code to update its pinned version. GitHub Actions standard hosted runners may have quota restrictions depending on repository visibility and subscription; Ollama itself has no per-token fee, but local electricity and network charges remain.

The installer resolves existing GitHub CLI, Ollama and Python launcher paths even when the current terminal has a stale PATH; it only invokes winget when the executable cannot be located. It also passes those executable directories into the scheduled task's environment. A Git for Windows installation is not required by the Guardian local runner.

## Optimization reviews and first test run

The Windows installer re-registers the hourly local task **and immediately runs one local audit/optimization review synchronously**. A successful task registration alone is not a successful model invocation; review `%LOCALAPPDATA%\\WoW112Guardian\\last_run.json` and `last_run.log` to confirm the reviewed branch, exact HEAD, source and outcome. A run may take several minutes if Ollama is invoked. This initial run does **not** run WoW or benchmark in-game performance. Existing CI failures remain visible in GitHub's hourly audit; the local model independently searches for optimization opportunities in eligible active development sources. If it proposes a bounded change, it opens an isolated draft PR and dispatches the exact-SHA Windows x86 candidate verification. Approval, measurable performance improvement and gameplay testing remain separate requirements. Update your already-installed local task by rerunning the latest installer from `main` to pick up the new script; GitHub cannot execute Ollama on your local Windows PC remotely.

# `source/` — legacy / historical material

This directory is retained for rollback evidence and old recovery material.

**Do not use this directory as the normal editable source root.**

Active canonical source paths must be under `src/` and are selected by `runtime/current.json`.

Contents such as `V20_SOURCE_PARTS/` and historical patch files may be useful for reconstruction/audit, but they are not authoritative for the current runtime unless explicitly referenced as recovery evidence.

New active source files must not be added here.

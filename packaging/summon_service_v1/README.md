# Summon Service V1 packaging

Windows 11 operator packaging for Summon Service V1. This directory deliberately contains **no summon implementation** and no AH functionality.

Production packages are generated by `scripts/Build-Package.ps1` from two already-built runtime executables. The builder stamps an exact source SHA, computes SHA256 for every immutable artifact, emits `<package>.sha256`, and creates the one-folder distribution. CI additionally creates a clearly marked `DEMO_ONLY` package using test stubs; that artifact validates packaging UX and must never be used as the real summon service.

See `docs/ARTIFACT_CONTRACT.md` and `docs/DEPLOYMENT.md`.
